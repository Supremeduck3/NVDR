Progressive Residual Stack

Codifica uma imagem em .nvdr e decodifica cada camada no navegador. O anchor sozinho já é uma imagem inteira; cada resíduo melhora o que já está na tela.

Solte uma imagem aqui ou clique para escolher

JPG, PNG, BMP, WEBP, GIF ou TGA

Camadas

Bytes acumulados são gzip por nível, medidos no servidor.

Entrega parcial

Arraste para simular um download interrompido. O decoder mostra o último nível cujos bytes chegaram inteiros — nunca espera, nunca falha no meio. A fração é sobre o container cru: comprimir tudo de uma vez tornaria qualquer prefixo indecodificável, então os níveis teriam que comprimir separadamente para as duas propriedades valerem juntas.
